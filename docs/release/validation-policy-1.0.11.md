# EZTerminal 1.0.11 검증 정책과 잔여 위험

## 지원 기준

- Windows 10 22H2 또는 Windows 11 x64 데스크톱 앱과 원격 호스트 서비스
- Android 10(API 29) 이상 Capacitor 클라이언트
- Tailscale/WireGuard 또는 사용자가 명시적으로 선택한 VPN 인터페이스
- 잠금되지 않은 일반 사용자 데스크톱의 원격 화면·입력 제어

## 이번 릴리스의 성격

모바일 표현 계층 전면 개편입니다. WS 프로토콜, `EzTerminalApi`, BlockController,
세션·에이전트·PC 제어 로직은 변경하지 않았고 `protocolVersion`은 2로 유지됩니다.
데스크톱 제품 코드는 i18n 리소스 추가 외에 변경이 없습니다.

## 릴리스 게이트

- 동일한 깨끗한 Git SHA에서 버전 계약, 타입 검사, 린트, 루트·모바일 단위
  테스트와 일반 데스크톱 E2E(`pnpm e2e`)를 실행합니다.
- 모바일 번들은 WebView 74 호환 계약과 프로덕션 E2E 마커 부재를 검증하고,
  최종 APK의 `assets/*` 엔트리를 직접 스캔해 `[ez-e2e]` 문자열이 없음을
  확인합니다.
- Storybook 시각 계약을 360×800 / 412×915 / 600×960 / 915×412 뷰포트에서
  실행하고, 각 스토리의 WCAG 2.1 A/AA 검사를 통과시킵니다.
- **API 35와 API 29 에뮬레이터에서 모바일 기능 전수 검증을 수행합니다**:
  페어링, 터미널 생성·실행, 탭 keep-alive, 세션 시트 전환, 파일 다운로드·업로드
  왕복, 모니터·패킷, 테마·폰트·이펙트 영속, Android 뒤로 가기 계층, 앱 강제
  종료 후 세션 재개(즉시 및 330초 임대 만료), 대량 출력 재개, 폴드 커버·메인
  지오메트리와 회전.
- Windows 설치 파일과 Android 프로덕션 APK를 같은 SHA에서 빌드하고, APK는 기존
  장기 키로 서명한 뒤 버전·인증서 지문을 확인합니다.
- 기능 변경 릴리스이므로 `pnpm e2e:performance`,
  `e2e/release-performance.spec.ts`, `-RunPerformanceMeasurement`를 실행하지
  않습니다. 과거 보고서를 새 SHA의 성능 증거로 재사용하지 않습니다.

## 알려진 기능 제한

- 잠금 화면과 UAC 보안 데스크톱 캡처·입력은 지원하지 않습니다.
- Software SAS와 Ctrl+Alt+Delete는 지원하지 않습니다.
- 모바일 CRT 이펙트는 기본 꺼짐이며, 기기의 애니메이션 제거 설정이 켜져 있으면
  움직이는 이펙트는 의도적으로 비활성화됩니다.

## 수용된 잔여 위험

- 이번 SHA에 대한 데스크톱 성능 회귀 비교와 30분 모바일 소크를 수행하지
  않으므로 이 릴리스는 두 결과를 주장하지 않습니다. 검증 프로필은
  `functional-hotfix`입니다.
- **PC 제어 몰입 화면은 에뮬레이터 자동 검증 대상이 아닙니다.** 원격 화면 캡처는
  Windows 호스트 서비스를 요구하므로, 이번 개편의 PC 제어 크롬(자동 숨김,
  상태 필, 모드 전환)은 수동 확인에 의존합니다. 입력 매핑·임대·클립보드 계약
  자체는 변경하지 않았습니다.
- 에이전트 화면은 단위 테스트로 검증했으며(버킷 분류, 필터, 정렬, 후속 전송
  성공·실패, 세션 포커스, 빈 상태, 연결 끊김 가드), 실제 에이전트가 붙은
  기기 시나리오는 자동화하지 않았습니다.
- 실기기 검증은 Galaxy Z Fold 1대에서 수동으로만 수행했습니다. OEM별 Android
  프로세스 정책, 디코더, TalkBack, 하드웨어 키보드는 자동 검증하지 않습니다.
- Windows 10/Home/Enterprise, 도메인 및 MDM 정책 경로는 자동 검증하지
  않습니다.
- 멀티 모니터, HDR 및 공급업체별 GPU 인코더 경로는 자동 검증하지 않습니다.
