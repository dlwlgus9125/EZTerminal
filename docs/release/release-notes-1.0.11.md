# EZTerminal 1.0.11

## 모바일 상용화 UI/UX

안드로이드 컴패니언의 정보 구조를 **하단 탭바 5개**로 교체했습니다. 인증 직후
허브를 거쳐 목적지로 들어가던 구조 대신, 홈 · 터미널 · PC · 에이전트 · 더보기가
항상 화면에 남아 한 번의 탭으로 이동합니다.

- **홈 탭**: PC 제어 히어로(가용 여부와 명시적 시작 버튼), 최근 세션 3개,
  응답을 기다리는 첫 에이전트, 그리고 게이트웨이가 실행 중일 때만 나타나는
  OpenClaw 바로가기.
- **PC 탭은 목적지가 아니라 시작 동작입니다.** 탭해도 캡처가 자동으로 시작되지
  않으며, 기존 임대·백그라운드·연결 해제 안전 계약은 그대로입니다.
- **더보기 시트**: 세션 관리, 파일, 모니터, OpenClaw, 테마, 설정.
- **펼침 디스플레이(600dp 이상)**: 탭바가 좌측 72px 레일로 바뀝니다. 항목과
  순서는 동일하고, 콘텐츠는 520px 중앙 단일 컬럼을 유지합니다.

## 터미널

- 헤더의 탭 스트립이 **세션 드롭다운 + 바텀시트**로 바뀌었습니다. 탭 사이
  스와이프 전환은 헤더에서 그대로 동작합니다.
- 블록 목록 아래에 **상태 라인**(작업 경로 · 마지막 실행 결과 · PTY 그리드),
  컴포저, **최근 명령 칩 행**, 액세서리 키바가 차례로 놓입니다.
- 소프트 키보드에 Ctrl 키가 없는 기기를 위해 **Ctrl 래치**를 더했습니다. 기존
  Ctrl+문자 → 제어 바이트 규칙을 그대로 사용하며, PTY에 닿는 바이트는
  달라지지 않습니다.

## 에이전트

필터 칩(전체 · 주의 · 실행 중 · 완료)과 상태별 카드로 재구성했습니다. 승인이
필요한 항목은 해당 터미널 세션으로 바로 이동하고, 응답을 기다리는 항목은 기존
후속 메시지 전송을 그대로 사용합니다. 에이전트 프로토콜은 변경되지 않았습니다.

## PC 제어

원격 화면이 전체를 채우고 모든 컨트롤이 위에 떠 있는 몰입 화면이 되었습니다.
마지막 터치 후 3.5초가 지나면 컨트롤이 사라지고, 다시 화면을 만지면 돌아옵니다.
화면 탭은 원격 클릭이므로 컨트롤 토글에 쓰지 않습니다.

## 설정 · 연결

- 설정 인덱스 상단에 연결 카드(호스트, 엔드포인트, 접속 시간, 연결 해제)를 두고,
  각 카테고리 행이 **현재 값을 그대로 보여줍니다**.
- 페어링 화면에 저장된 연결 카드와, 링크 수립 중 단계별로 나타나는 부트 로그를
  더했습니다.

기존 설정 키, 테마·커스텀 테마 포맷, 액세서리 키 구성은 모두 그대로입니다.

## 수정

- 더보기 시트에서 목적지를 몇 번 오간 뒤 Android **뒤로 가기가 앱을 종료**하던
  문제를 고쳤습니다. 시트가 페이지로 바뀔 때마다 히스토리 항목이 하나씩 새어
  논리적 레이어 스택과 브라우저 히스토리가 어긋나던 것이 원인이며, 에뮬레이터
  전수 검증에서 발견했습니다.

## 알려진 제한

- 모바일 CRT 이펙트(스캔라인 · 롤 바 · 인광 잔상)는 이전과 동일하게 **기본
  꺼짐**입니다. 설정 → 모양 → 이펙트에서 켤 수 있습니다.
- 기기의 애니메이션 제거 설정이 켜져 있으면 움직이는 이펙트(롤 바 등)는 의도적으로
  비활성화됩니다.
- 잠금 화면과 UAC 보안 데스크톱, Ctrl+Alt+Delete는 1.0.11에서도 지원하지 않습니다.
