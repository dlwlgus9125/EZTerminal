# EZTerminal 1.0.8

## 데스크톱 분할 페인 컨텍스트 메뉴 복구

- 가로 또는 세로로 분할한 터미널 페인의 빈 배경, 명령 입력, 렌더링된 출력에서
  우클릭 메뉴가 열리지 않던 문제를 수정했습니다.
- 일반 출력, plain PTY, 전체 xterm 세션에서 컨텍스트 메뉴 동작을 일관되게
  유지합니다.
- 복사, 붙여넣기, 전체 선택이 메뉴를 연 페인의 입력 또는 출력에만 적용되며,
  `Shift+F10`과 Context Menu 키를 통한 키보드 호출도 지원합니다.
- 메뉴를 닫을 때 원래 페인의 포커스와 선택을 복원하고, 다른 페인을 클릭해
  닫은 경우에는 새로 선택한 페인의 포커스를 유지합니다.
- Dockview 분할 레이아웃의 변환 좌표가 메뉴 위치를 이중으로 이동시키지 않도록
  메뉴를 문서 루트에 렌더링합니다.

## 회귀 방지

- 가로·세로 분할, 빈 페인, 입력·출력 작업, xterm 단일 메뉴, 페인 간 포커스
  이동을 Electron E2E로 검증합니다.
- 공유 컨텍스트 메뉴의 위치, 키보드 탐색, 선택 유지와 비동기 클립보드 붙여넣기
  동작을 단위 테스트로 고정했습니다.

## 검증 범위

- 타입 검사, 린트, Rust·루트·모바일 단위 테스트, 일반 `pnpm e2e`, Windows
  패키징, Android API 29/35 검증을 수행합니다.
- 기능 핫픽스 정책에 따라 릴리스 성능 벤치마크와 30분 모바일 소크는 실행하지
  않으며, 새 exact-SHA 성능 비교 결과를 주장하지 않습니다.

자세한 지원 범위와 잔여 위험은
[1.0.8 검증 정책](validation-policy-1.0.8.md)을 확인하세요.
