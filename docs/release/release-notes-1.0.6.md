# EZTerminal 1.0.6

## 모바일 세션 재개

- 모바일에서 시작한 PTY가 실행 중인 상태로 Android 앱을 강제 종료한 뒤 다시
  열어도, 동일한 앱 설치 ID가 5분 리스 안에 재접속하면 출력뿐 아니라 입력
  제어권까지 복구합니다.
- 다른 모바일 연결이 관찰 목적으로 붙은 세션은 재접속 후에도 보기 전용으로
  유지되어 제어권을 잘못 가져오지 않습니다.
- Android 10(API 29) 에뮬레이터에서 앱 강제 종료, 프로세스 재생성, 기존 출력
  재생, 같은 PTY로의 새 입력 전달을 하나의 시나리오로 재현 검증했습니다.

## 데스크톱 복구와 유지보수

- 직접 실행한 Codex 터미널이 중단 상태에 머물 때 사용할 수 있는 명시적 복구
  동작을 추가했습니다.
- OpenClaw 노출 정책과 주요 파일·상태·설정 화면의 단위 회귀 검증을 보강하고,
  오래된 임시 계획·스파이크·중복 E2E 자산을 정리했습니다.

## 검증 범위

- 타입 검사, 린트, 루트·모바일 단위 테스트, 일반 `pnpm e2e`, Windows 패키징,
  Android 빌드와 API 29 강제 종료/재실행 시나리오를 검증했습니다.
- 운영자의 명시적 요청에 따라 릴리스 성능 벤치마크는 실행하지 않았습니다.
  따라서 이 버전은 새 exact-SHA 성능 비교 결과를 주장하지 않습니다.

자세한 지원 범위와 잔여 위험은
[1.0.6 검증 정책](validation-policy-1.0.6.md)을 확인하세요.
