# EZTerminal 1.0.9

## Android 장시간 세션 제어권 복구

- Android에서 시작한 Codex/PTY 실행을 둔 채 앱 프로세스가 종료되고 5분이
  지나도, 같은 모바일 설치가 재접속하면 원래 실행의 입력 제어권을 자동으로
  복원합니다.
- 5분 제한은 연결이 끊긴 `MessagePort`를 보존하는 임대에만 적용합니다.
  실행을 시작한 모바일 설치의 신원은 실행이 실제로 끝날 때까지 별도로
  유지합니다.
- 실행 종료, 세션 삭제, 인터프리터 종료 또는 사용자가 명시적으로
  Disconnect한 경우에는 복원 자격을 즉시 제거합니다.
- 모바일이 직접 만든 실행에서 제어권 전환 버튼이 보이지 않는 것은 이미 해당
  설치가 입력 소유자이기 때문이며, 데스크톱과 모바일에 중복된 제어 UI가
  존재해서가 아닙니다.

## 회귀 방지

- 포트 임대가 만료된 뒤에도 활성 실행의 `resumeOwned` 신원이 유지되고 입력
  제어권을 다시 획득하는 원격 브리지 회귀 테스트를 추가했습니다.
- 실제 Android 앱 강제종료 후 330초 동안 원래 PTY를 유지한 다음, 출력 재생,
  자동 제어권 복원 및 같은 PTY로의 입력 전달을 검증했습니다.
- 실행 시작 실패에는 복원 신원을 남기지 않고, 정확히 일치하는 실행 종료
  이벤트만 신원을 정리하도록 브로커 수명주기 테스트를 추가했습니다.

## 검증 범위

- 버전 계약, 타입 검사, 린트, Rust·루트·모바일 단위 테스트, 일반
  `pnpm e2e`, Windows 패키징, Android API 29/35 검증을 릴리스 게이트로
  수행합니다.
- 기능 핫픽스 정책에 따라 릴리스 성능 벤치마크와 30분 모바일 소크는 실행하지
  않으며, 새 exact-SHA 성능 비교 결과를 주장하지 않습니다.

자세한 지원 범위와 잔여 위험은
[1.0.9 검증 정책](validation-policy-1.0.9.md)을 확인하세요.
