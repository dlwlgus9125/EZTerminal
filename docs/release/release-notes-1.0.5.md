# EZTerminal 1.0.5

## PC Control 화면 동기화

- Windows 원격 호스트를 Per-Monitor DPI Awareness v2로 실행해 125% 이상의
  디스플레이 배율에서도 모니터의 물리 픽셀 전체를 캡처합니다.
- 모바일의 실제 영상 영역과 기기 픽셀 비율을 호스트에 전달하고, 회전·접힘·창
  크기 변경 후에도 화면 전체가 종횡비를 유지한 채 중앙에 표시됩니다.
- 스트림 해상도는 모바일 뷰포트와 현재 품질 단계보다 커지지 않으며 업스케일하지
  않습니다.

## 모바일 제어 성능

- 인코딩 해상도에 비례해 비트레이트를 조정합니다.
- 캡처·인코딩 파이프라인 부하와 모바일 수신 드롭 프레임을 품질 단계 판단에
  반영합니다.
- 포인터 데이터 채널에 백프레셔가 생기면 이동 이벤트를 병합해 오래된 입력이
  쌓이지 않도록 했습니다.

## 호환성과 제한

- 공개 원격 프로토콜 v2에는 선택적 뷰포트 필드만 추가되어 이전 클라이언트와
  호환됩니다.
- Windows 내부 원격 호스트 프로토콜은 v2이므로 데스크톱 앱과 원격 호스트
  서비스를 함께 업데이트해야 합니다.
- 잠금 화면과 UAC 보안 데스크톱 캡처·입력, Software SAS 및
  Ctrl+Alt+Delete는 지원하지 않습니다.

자세한 지원 범위와 잔여 위험은
[1.0.5 검증 정책](validation-policy-1.0.5.md)을 확인하세요.
