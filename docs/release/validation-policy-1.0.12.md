# EZTerminal 1.0.12 검증 정책과 잔여 위험

## 지원 기준

- Windows 10 22H2 또는 Windows 11 x64 데스크톱 앱과 원격 호스트 서비스
- Android 10(API 29) 이상 Capacitor 클라이언트
- Tailscale/WireGuard 또는 사용자가 명시적으로 선택한 VPN 인터페이스
- 잠금되지 않은 일반 사용자 데스크톱의 원격 화면·입력 제어

## 이번 릴리스의 성격

데스크톱 표현 계층 전면 개편입니다. 1.0.11이 모바일에 한 작업의 데스크톱 짝이며,
PTY·IPC·세션·페어링·명령 시맨틱, Dockview 계약, 레이아웃 스키마는 변경하지
않았고 `protocolVersion`은 2로 유지됩니다.

모바일 제품 코드는 변경하지 않았습니다. 다만 공유 토큰 시트(`ui-tokens.css`)와
공유 i18n 리소스를 데스크톱과 함께 쓰므로 모바일 번들도 다시 빌드되며,
그에 따라 `androidVersionCode`를 33으로 올립니다.

`SettingsSchema`에 선택 필드 `bootIntro` 하나가 추가되었습니다. schemaVersion은
1로 유지되며, 이 필드가 없는 기존 `settings.json`은 그대로 파싱되어 기본값을
따릅니다.

## 릴리스 게이트

- 동일한 깨끗한 Git SHA에서 버전 계약, 타입 검사(데스크톱·모바일 E2E), 린트,
  루트 단위 테스트와 OS 통합 테스트, 일반 데스크톱 E2E(`pnpm e2e`)를 실행합니다.
- 네이티브 패키징 가드 3종(`guard:native`, `guard:native-cap`,
  `guard:pty-routing`)으로 conpty·cap 네이티브 모듈의 asar 언팩과 PTY 라우팅
  불변식을 확인합니다.
- Storybook 시각 계약을 800×600 / 1024×720 / 1200×800 / 1440×900 데스크톱
  뷰포트와 100%·150% 배율에서 실행하고, 각 스토리의 WCAG 2.1 A/AA 검사를
  통과시킵니다. 헤더 컨트롤 비겹침은 4개 폭 × 2개 배율 전 조합에서 확인합니다.
- **패키징된 exe 자체를 `pnpm test:e2e:packaged`로 검증합니다.** 개발 모드
  E2E는 asar 언팩·CSP·번들 폰트 경로를 덮지 못합니다.
- 모바일 번들은 프로덕션 E2E 마커 부재(`verify:mobile-release`)를 검증하고,
  최종 APK의 `assets/*` 엔트리를 직접 스캔해 `[ez-e2e]` 문자열이 없음을
  확인합니다.
- Windows 설치 파일과 Android 프로덕션 APK를 같은 SHA에서 빌드하고, APK는 기존
  장기 키로 서명한 뒤 버전·인증서 지문을 확인합니다.
- 기능 변경 릴리스이므로 `pnpm e2e:performance`,
  `e2e/release-performance.spec.ts`, `-RunPerformanceMeasurement`를 실행하지
  않습니다. 과거 보고서를 새 SHA의 성능 증거로 재사용하지 않습니다.

## 이번 개편에서 핸드오프와 다르게 구현한 것

디자인 핸드오프가 전제했지만 코드에 대응물이 없어, 없는 데이터를 만들지 않고
실제 계약에 맞춰 각색한 항목입니다. 릴리스 노트와 동일한 내용을 검증 기준으로
고정합니다.

- 에이전트 허브에 승인·거부 버튼을 넣지 않았습니다. 승인은 터미널에서만
  이루어지며, 에이전트 활동 서비스는 차단된 승인에 직접 쓰지 않습니다.
- 실행 중 진행률은 완료 비율이 아니라 무한 스윕입니다. 활동 스냅샷에 진행률
  필드가 없습니다.
- Command Center 키캡은 실제 단축키인 `Ctrl Shift P`를 표시합니다.
- OpenClaw 채팅 말풍선은 구현 대상이 아닙니다. 채팅 렌더링은 네이티브
  `WebContentsView` 안의 OpenClaw Control UI가 소유합니다.
- QR 페어링 모달은 이번 릴리스에 포함하지 않습니다. 현재 페어링 토큰은 만료가
  없고 재사용 가능하므로 "유효시간 카운트다운·1회용" 표기는 사실과 다른 보안
  안내가 됩니다.

## 알려진 기능 제한

- 잠금 화면과 UAC 보안 데스크톱 캡처·입력은 지원하지 않습니다.
- Software SAS와 Ctrl+Alt+Delete는 지원하지 않습니다.
- 부팅 시퀀스는 기본 켜짐이며, 시스템의 애니메이션 제거 설정이 켜져 있으면
  재생하지 않고 건너뜁니다. 설정 → 모양에서 끌 수 있고 변경은 다음 실행부터
  적용됩니다.

## 수용된 잔여 위험

- 이번 SHA에 대한 데스크톱 성능 회귀 비교와 30분 모바일 소크를 수행하지
  않으므로 이 릴리스는 두 결과를 주장하지 않습니다. 검증 프로필은
  `functional-hotfix`입니다.
- **작업영역 페인의 카드 거터는 Dockview의 리프 뷰 padding으로 만듭니다.**
  Dockview가 뷰를 절대 좌표로 배치하므로 이 방식이 강제되며, 분할·드래그·탭·
  레이아웃 영속 E2E가 그 격자 계산의 유일한 증거입니다. 스크린샷은 이 부분을
  검증하지 못합니다.
- **부유 컴포저는 페인의 자식으로 남아 있습니다.** 페인별 초안, 붙여넣기 안전
  경고, IME 조합, 평문 PTY 키 입력 경로가 그 계약이며 위치가 아닙니다.
- 장식용 토큰(`--ui-text-dim`, `--ui-border-mid`, `--ui-border-focus-soft`,
  `--ui-glow-*`)은 `UiThemeColors` 밖에 있어 런타임 대비 보정을 받지 않습니다.
  대신 `ui-tokens.test.ts`가 4개 내장 테마 × 각 서피스 조합의 대비를 직접
  계산해 고정합니다. 사용자 커스텀 테마는 17개 시맨틱 롤만 제공하므로 이
  장식 롤들은 보정된 롤로 폴백합니다.
- 데스크톱 실기기 검증은 Windows 11 Pro 1대에서 수동으로 수행합니다. Windows
  10/Home/Enterprise, 도메인 및 MDM 정책 경로는 자동 검증하지 않습니다.
- 모바일 제품 코드는 변경하지 않았으나 공유 토큰·i18n 변경으로 번들이 다시
  빌드됩니다. API 29/35 에뮬레이터 기능 검증은 릴리스 워크플로가 수행합니다.
- 멀티 모니터, HDR 및 공급업체별 GPU 인코더 경로는 자동 검증하지 않습니다.
