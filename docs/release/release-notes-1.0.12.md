# EZTerminal 1.0.12

## 데스크톱 상용화 UI/UX

1.0.11이 안드로이드에 한 작업의 데스크톱 짝입니다. 워크벤치 전체를 같은
CRT/Matrix 언어로 다시 맞췄고, PTY·IPC·세션·페어링·명령 시맨틱과 Dockview 계약,
레이아웃 스키마는 건드리지 않았습니다.

## 셸

- **헤더**가 60px로 커지고, Command Center 존이 **중앙 검색 필드**가 됐습니다.
  필드는 앵커일 뿐 입력 상태를 갖지 않으며, 클릭하면 기존 Command Center가
  그대로 열립니다. 실제 단축키인 `Ctrl Shift P`를 키캡으로 표시합니다.
- 워드마크 옆에 **빌드 버전 칩**이 붙습니다. 헤더가 좁아지면 가장 먼저
  접히는 요소입니다. 정보이지 내비게이션이 아니고 같은 값이 설정에도 있습니다.
- `FX · <프로필>` 컨트롤이 알림 옆(존 4)으로 옮겨져 검색 필드가 가운데를
  온전히 차지합니다. 헤더는 여전히 정확히 4개 존입니다.
- **액티비티 레일**이 62px로 넓어지고 버튼이 44px가 됐습니다.
- 사이드바 목적지를 바꿀 때 페이드 + 8px 상승 전환이 붙습니다.

## 작업영역

- **페인이 카드가 됩니다.** 12px 라운드, 테두리, 14px 거터, 포커스된 페인의
  글로우. 거터는 Dockview 리프 뷰의 padding으로 만듭니다 — Dockview가 뷰를
  절대 좌표로 배치하므로 그룹에 margin을 주면 배치 계산이 깨집니다.
- **컴포저가 페인 하단 중앙에 떠 있는 820×48 필**이 됐습니다. 컴포저는 여전히
  페인의 자식이라 페인별 초안 격리, 붙여넣기 안전 경고, IME 조합, 평문 PTY 키
  입력 경로가 전부 그대로입니다. 키보드가 말을 걸고 있는 페인의 컴포저만
  액센트 테두리를 갖고, 나머지도 계속 클릭할 수 있습니다 — 클릭이 곧 그
  페인으로 포커스를 옮기는 방법이기 때문입니다.

## 패널

- **Command Center**: 660px, 그룹 헤딩과 인셋 액센트 바로 선택 행 표시, 키 힌트
  푸터. 행 제공자·그룹·키보드 모델·포커스 복원은 전부 그대로입니다.
- **에이전트 허브**: 위험도 색 카드, 승인 대기 상태의 점멸 점, 모노 인셋 작업
  경로, 실행 시간 표시.
- **모니터**: 24px 스코프 격자를 가진 계측 카드. 섹션 제목이 하드코딩 영문
  약어에서 리소스 키로 바뀌어 한국어로도 나옵니다. 상세 지표가 패널이 열려
  있는 동안에만 수집된다는 사실을 화면에 명시합니다.
- **OpenClaw**: 세션 수 · 누적 토큰 · 게이트웨이 포트 3칸 콘솔 판독부.
- **탐색기**: 클릭 가능한 **경로 브레드크럼**과 그 아래 전체 경로 모노 표시.
  기존 자유 입력 경로 칸은 그대로 남습니다.
- **다이얼로그**: 위험도를 알리는 4px 상단 레일과 180ms 진입 모션. 색만으로
  의미를 전달하지 않습니다 — 제목과 본문, 파괴적 동작의 스타일이 함께 말합니다.
- **토스트**가 우하단으로 내려가고 4.2초로 짧아졌습니다. 우상단은 헤더 자신의
  컨트롤 자리이고, 완료 알림이 사용자가 손을 뻗는 내비게이션을 덮지 않습니다.

## 부팅 시퀀스

실행할 때 CRT 전원 인가 시퀀스가 재생됩니다. 화면 열림 → 빔 → 워드마크 →
초기화 로그 5줄, 약 3초입니다.

- 순수 가산입니다. 워크벤치는 그 아래에서 평소대로 마운트·페인트되고 상호작용
  가능해집니다. 첫 페인트를 막지 않습니다.
- 클릭이나 아무 키로 건너뜁니다.
- **시스템의 애니메이션 제거 설정이 켜져 있으면 재생하지 않고 건너뜁니다.**
  전부가 타이밍인 시퀀스는 타이밍을 없애면 보여줄 것이 남지 않습니다.
- 설정 → 모양의 `실행 시 부팅 시퀀스 재생`으로 끕니다. 변경은 다음 실행부터
  적용됩니다.

## 접근성과 테마

- 새 장식용 색 역할은 커스텀 테마가 제공하는 17개 시맨틱 롤로 폴백합니다.
  17개만 정의한 사용자 테마도 읽을 수 있는 상태로 유지됩니다.
- 4개 내장 테마 × 각 서피스 조합의 대비를 토큰 계약 테스트가 직접 계산해
  고정합니다. 본문 4.5:1, 모달·페인 경계 3:1입니다.
- 라이트와 고대비 테마는 인광 글로우를 끕니다.

## 핸드오프와 다르게 구현한 것

디자인이 전제했지만 코드에 대응물이 없어, 없는 데이터를 만드는 대신 실제 계약에
맞춰 각색했습니다.

- 에이전트 허브에 승인·거부 버튼은 없습니다. 승인은 터미널에서 이루어지고,
  활동 서비스는 차단된 승인에 직접 쓰지 않습니다. 카드는 결정처럼 보이지만
  결정은 원래 있던 곳에서 일어납니다.
- 실행 중 진행률은 완료 비율이 아니라 무한 스윕입니다. 아무것도 측정하지 않는
  숫자를 화면에 띄우는 것보다 낫습니다.
- 키캡은 `Ctrl K`가 아니라 `Ctrl Shift P`입니다. Ctrl+K는 readline의
  줄 끝까지 삭제이고 핸들러가 캡처 단계에서 돌기 때문에, 그 조합을 가져가면
  터미널이 키를 받기 전에 삼켜집니다.
- OpenClaw 채팅 말풍선은 대상이 아닙니다. 채팅 렌더링은 네이티브
  `WebContentsView` 안의 OpenClaw Control UI가 소유합니다.
- QR 페어링 모달은 포함하지 않았습니다. 현재 페어링 토큰은 만료가 없고 재사용
  가능하므로 "유효시간 카운트다운 · 1회용" 표기는 사실과 다른 보안 안내입니다.

## 함께 고친 것

- 모든 사이드바 목적지 아래에 있던 유령 가로 스크롤바. 크기 조절 손잡이가
  스크롤 컨테이너 안에 있는데 음수 인셋으로 4px 밖에 나가 있었습니다.
- 페이스트 경고 다이얼로그의 시각 기준선이 제품과 달랐습니다. 그 다이얼로그의
  스타일 시트를 스토리가 불러오지 않아, 기준선이 브라우저 기본 목록을 찍고
  있었습니다.

## 설치

- Windows: `EZTerminal-Setup.exe` — 무서명이므로 SmartScreen이 알 수 없는
  게시자 경고를 표시합니다. 기존 설치 위에 덮어써도 `%APPDATA%\EZTerminal`
  사용자 데이터와 레이아웃·설정은 보존됩니다.
- Android: `EZTerminal-Android-1.0.12-vc33.apk` — 제품 코드 변경은 없지만
  데스크톱과 공유하는 토큰·i18n 리소스가 바뀌어 번들을 다시 빌드했습니다.
- 두 앱의 `protocolVersion`은 2로 유지되므로 1.0.11과 서로 연결됩니다.

검증 범위와 수용한 잔여 위험은
[1.0.12 검증 정책](validation-policy-1.0.12.md)에 고정합니다.
