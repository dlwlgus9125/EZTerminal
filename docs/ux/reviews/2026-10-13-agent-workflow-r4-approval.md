# 소프로젝트·일반 대화·실행 흐름 r4 승인

2026-10-13 사용자가 **“승인”**, **“각 구현은 멀티에이전트로하고 이 세션은 검수를 한다”**고 지시했다.
[개선 계획](../agent-workflow-plan.md)과 [r4 시안](../reference/v2-agent-chat-r4/index.html)을
구현 기준으로 확정하며, 구현 에이전트의 변경을 이 세션에서 검토·통합·검증한다.

- 승인 범위: 첫 대화 전 기능 탐색과 native 확장 관리, 프로젝트의 동등한 소프로젝트·일반 대화,
  프리셋/대화 생성, 편집 가능한 실행 그래프, 단계별 여러 대화, AI 초안 직접 수정과 되돌리기,
  실행 버전 고정, Desktop·Android 연결.
- 승인 발화·범위·원본 SHA-256: [승인 manifest](2026-10-13-agent-workflow-r4-approval.json).
- 승인 당시 시안 manifest와 계획·UX 문서는 `r4-approved/`에 원본 바이트로 보존한다.
  이후 소스 변화는 새 구현으로 검수하며, 과거 fingerprint를 현재 값으로 덮어쓰지 않는다.
- 원래 r4 manifest의 `review-pending`은 시안 생성 당시 상태다. 현재 설계 승인 여부는 이 기록이 소유한다.
  시안의 245개 통과 기록은 과거 예시 UI 검증이며 실제 제품 검증으로 재사용하지 않는다.

사용자 발화의 정확한 전송 시각은 제공되지 않았다. manifest 시각은 기록 생성 시각이다.
이 승인은 개별 화면 전수 검토, 구현 완료, 실제 AI 실행·물리 기기·성능 검증 통과를 뜻하지 않는다.
기존 r6와 r1–r4 원본, 고정 desktop handoff를 보존한다.

성능 측정, commit·push·배포, 외부 Codex/Claude 앱에서 EZTerminal 전용 흐름 스킬을 사용하는
확장은 이번 구현 승인의 범위에 포함하지 않는다.
