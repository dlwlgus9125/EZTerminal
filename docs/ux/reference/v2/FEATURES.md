# EZTerminal 2.0 기능명세

상태: r6 사용자 설계 승인 · 구현 진행 허가. [승인 기록](APPROVAL.md). 원본: [content.mjs](content.mjs). [확정 정책](POLICIES.md)과 [동작·복구 계약](POLICY-CONTRACTS.md)을 함께 따른다.

## F01 프로젝트와 시작

같은 결과를 만드는 대화·기획·작업의 맥락을 잃지 않는다.

- **시작:** 홈에서 작업 종류를 선택하거나 기존 폴더를 연다.
- **동작:** 새 제품은 PRD부터, 빠른 작업은 목적·대상·완료 조건부터 시작한다. 일반 대화와 터미널은 기존 Local 맥락을 재사용한다.
- **화면:** [D01](SCREENS.md#d01), [D02](SCREENS.md#d02), [D03](SCREENS.md#d03), [D43](SCREENS.md#d43), [M02](SCREENS.md#m02), [M03](SCREENS.md#m03)

수용 기준:

- 취소만으로 프로젝트나 프로세스를 생성하지 않는다.
- 같은 세션을 다시 열어도 실행을 중복 생성하지 않는다.

## F02 대화와 두 가지 스킨

편한 표현을 선택하면서도 AI 작업의 의미와 제어를 유지한다.

- **시작:** 메시지를 보내거나 보기 메뉴에서 스킨을 바꾼다.
- **동작:** 말풍선·터미널형에서 동일한 메시지, 도구 결과, 첨부, 승인, 대기열을 표시한다. 스킨은 기기별 보기 설정이다.
- **화면:** [D01](SCREENS.md#d01), [D18](SCREENS.md#d18), [D39](SCREENS.md#d39), [M04](SCREENS.md#m04), [M14](SCREENS.md#m14)

수용 기준:

- 스킨 전환 후 작성 중 입력·스크롤·승인 대상이 유지된다.
- 터미널형 대화에서 셸 입력이 실행되지 않는다.
- IME 조합 중 Enter는 전송하지 않는다.
- 목표·대상·범위·완료 조건을 담은 요약 카드에서 사용자가 실행한다. 전체 PRD는 요구하지 않는다.
- 최근 동기화 내용 열람과 메시지 초안 작성을 허용한다. 마지막 동기화 시점을 표시하며 재연결 후 사용자가 확인해 전송한다.
- 말풍선과 CLI 스킨은 같은 메시지 ID·첨부·답장·도구 결과·승인·대기열을 사용하며 보기만 바꾼다. 입력은 하단의 채팅 composer에 유지한다.

## F03 자료와 참조

AI가 무엇을 근거로 수정하는지 확인한다.

- **시작:** 자료를 첨부하거나 @로 항목·파일·화면을 고른다.
- **동작:** 출처와 확인 시각, 항목 ID·버전을 보존한다. 텍스트·Markdown·JSON·PDF·이미지를 입력 자료로 사용하고 읽을 수 없는 자료는 첨부와 실패 원인을 유지한다.
- **화면:** [D02](SCREENS.md#d02), [D04](SCREENS.md#d04), [D05](SCREENS.md#d05), [D18](SCREENS.md#d18), [M04](SCREENS.md#m04)

수용 기준:

- 참조를 누르면 정확한 항목·버전·선택 위치로 이동한다.
- 추출 실패를 빈 문서로 처리하지 않는다.

## F04 연결된 기획

PRD와 기능명세가 화면 및 구현과 어긋나는 문제를 줄인다.

- **시작:** AI에게 기획 수정을 요청하거나 항목을 직접 편집한다.
- **동작:** PRD·요구사항·기능·수용 기준을 구조화한다. 직접 편집과 AI 편집은 같은 변경·이력 경로를 사용하며 의존 항목에 검토 필요를 표시한다.
- **화면:** [D05](SCREENS.md#d05), [D06](SCREENS.md#d06), [M05](SCREENS.md#m05)

수용 기준:

- 요구사항에서 연결된 기능과 화면을 찾을 수 있다.
- 외부 편집과 충돌하면 조용히 덮어쓰지 않는다.
- AI 변경 묶음 하나를 되돌릴 수 있다.

## F05 정보 구조와 사용자 흐름

버튼 뒤에 무엇이 일어나는지 구현 전에 결정한다.

- **시작:** 페이지·행동·분기·연결을 추가한다.
- **동작:** 페이지 계층과 정상·실패·취소 경로를 함께 편집한다. 그래프와 접근 가능한 단계 목록은 동일한 데이터를 사용한다.
- **화면:** [D06](SCREENS.md#d06), [D07](SCREENS.md#d07), [D08](SCREENS.md#d08), [M06](SCREENS.md#m06)

수용 기준:

- 목적지가 없는 이동과 도달할 수 없는 화면을 검출한다.
- 키보드와 모바일 속성 폼으로도 노드·연결을 수정할 수 있다.

## F06 화면 설계와 프로토타입

기획을 실제 화면과 동작으로 검토한다.

- **시작:** 화면을 생성하거나 요소를 선택해 AI에 수정 요청한다.
- **동작:** 요소·배치·상태·이동을 구조화된 scene으로 저장한다. 편집 모드와 체험 모드를 구분하며 화면 일부 수정·전체 재생성을 별도로 제공한다.
- **화면:** [D08](SCREENS.md#d08), [D09](SCREENS.md#d09), [D10](SCREENS.md#d10), [D11](SCREENS.md#d11), [D12](SCREENS.md#d12), [M06](SCREENS.md#m06)

수용 기준:

- 요소 ID와 기능 연결을 유지한다.
- 화면별 오류·빈 상태를 체험할 수 있다.
- 재생성은 확정본을 수정하지 않는다.
- 반복 요소를 공통 원본에 연결하고 화면별 예외를 허용한다. 공통 변경은 연결된 초안에 반영하며 승인된 확정본은 유지한다.

## F07 버전과 설계 확정

검토한 설계를 기준으로 실행하고 변경 범위를 추적한다.

- **시작:** 검토가 끝난 초안을 확정하거나 확정본에 수정을 요청한다.
- **동작:** 미해결 검토와 연결 누락을 검사한 뒤 immutable baseline을 만든다. 변경은 새 초안으로 분기하며 영향 작업만 다시 검토한다.
- **화면:** [D03](SCREENS.md#d03), [D05](SCREENS.md#d05), [D09](SCREENS.md#d09), [D11](SCREENS.md#d11), [D13](SCREENS.md#d13), [D15](SCREENS.md#d15), [D20](SCREENS.md#d20), [D44](SCREENS.md#d44), [M05](SCREENS.md#m05), [M08](SCREENS.md#m08)

수용 기준:

- 확정만으로 코드 실행이 시작되지 않는다.
- 진행 중 실행은 자신이 참조한 기준 버전을 유지한다.

## F08 AI 팀과 실행 관리

사람이 반복적으로 작업을 전달하지 않아도 책임과 진행을 확인한다.

- **시작:** 실행 준비에서 범위와 정책을 확인하고 시작한다.
- **동작:** 단계별 AI 프로필을 단일·분업·후보 비교·독립 검토 방식으로 운영한다. 대표 AI가 의존 작업을 구성하고 호스트가 상태·동시성·검증을 관리한다. 담당별 모델·작업 사본·변경 범위를 분리하고 직접 대화·질문·중단·재시도를 제공한다.
- **화면:** [D03](SCREENS.md#d03), [D15](SCREENS.md#d15), [D16](SCREENS.md#d16), [D17](SCREENS.md#d17), [D18](SCREENS.md#d18), [D19](SCREENS.md#d19), [D24](SCREENS.md#d24), [D27](SCREENS.md#d27), [D35](SCREENS.md#d35), [D44](SCREENS.md#d44), [M07](SCREENS.md#m07)

수용 기준:

- 선행조건이 충족되지 않은 작업은 실행되지 않는다.
- 동시 managed turn 상한 4를 지킨다.
- 완료에는 현재 작업·시도의 결과 revision과 검증 근거가 필요하다.
- 후보는 같은 입력·기준에서 독립 실행하며 채택과 통합을 구분한다.
- 프로필·도구 권한은 요청과 실제 적용값을 기록하며 실행 중 임의 변경하지 않는다.
- 자율 실행은 main 반영·push·배포를 자동 수행하지 않는다.
- 영향 작업과 후속 의존 작업만 멈추고 변경 계획·재작업 범위를 확인받아 재개한다. 무관한 작업과 이전 기준·결과는 유지한다.
- 최초 검증 실패 후 기본 최대 2회 추가 수정·재검증한다. 횟수는 설정 가능하며 소진 시 시도와 남은 문제를 보존하고 사용자 판단을 기다린다.
- 모델·추론·지시문·참조 문맥·허용 도구를 직접 편집하고 저장·버전·되돌리기를 제공한다. AI도 수정안을 만들 수 있다. 상위 권한은 유지한다.
- AI는 변경 전후와 이유를 제시한다. 사용자 적용 후 새 버전으로 저장하며 진행 중 시도는 고정된 설정을 유지한다.
- 전체 실행 시간 제한 없이 다음 검토·승인 지점까지 진행한다. 수동 중단과 검증 실패 재시도 제한은 유지한다.
- 해당 작업을 대기시키고 중단 이유와 대체 AI 선택지를 보여 준다. 임의로 전환하지 않으며 독립 작업은 계속한다.

## F09 편집·변경·결과 검토

AI의 설명뿐 아니라 실제 변경과 작동 결과로 판단한다.

- **시작:** 작업의 검토 요청을 열거나 파일·실행 요소를 선택한다.
- **동작:** 파일 편집, 전체 파일·diff, 실행 미리보기, 요소 주석, 검증 결과를 연결한다. 코드 기본 저장은 명시적 Save이며 자동 저장은 별도 선택이다.
- **화면:** [D17](SCREENS.md#d17), [D19](SCREENS.md#d19), [D20](SCREENS.md#d20), [D21](SCREENS.md#d21), [D22](SCREENS.md#d22), [D23](SCREENS.md#d23), [D24](SCREENS.md#d24), [D27](SCREENS.md#d27), [M08](SCREENS.md#m08)

수용 기준:

- 파일 저장 시 기준 revision을 비교한다.
- 대상 코드가 바뀌면 이전 검토의 유효성을 재확인한다.
- 출처 매핑이 없으면 소스 위치를 추측하지 않는다.

## F10 터미널과 파일 도구

대화 중심 작업에서도 실제 개발·운영 도구를 계속 쓴다.

- **시작:** 빠른 동작 또는 프로젝트에서 터미널·파일을 연다.
- **동작:** PTY, structured shell, CLI, 탭·분할·분리 창, 출력·입력·검색·기록을 유지한다. 파일과 코드 Project Map을 프로젝트 맥락에 연결한다.
- **화면:** [D01](SCREENS.md#d01), [D21](SCREENS.md#d21), [D28](SCREENS.md#d28), [D29](SCREENS.md#d29), [D30](SCREENS.md#d30), [D33](SCREENS.md#d33), [D40](SCREENS.md#d40), [D43](SCREENS.md#d43), [M09](SCREENS.md#m09), [M10](SCREENS.md#m10)

수용 기준:

- 탭 닫기와 세션 종료를 구분한다.
- Ctrl+C, 붙여넣기 확인, IME와 기존 터미널 입력 의미를 유지한다.

## F11 원격과 Android

이동 중에도 같은 작업을 확인하고 제어한다.

- **시작:** PC와 연결해 기획·대화·작업·PC 제어를 연다.
- **동작:** 같은 PC snapshot과 command 경로를 사용한다. 문서·요소를 터치용 폼으로 편집하고 terminal layer를 유지한다. PC 제어는 명시적으로 시작한다.
- **화면:** [D32](SCREENS.md#d32), [D33](SCREENS.md#d33), [D41](SCREENS.md#d41), [D44](SCREENS.md#d44), [M01](SCREENS.md#m01), [M02](SCREENS.md#m02), [M03](SCREENS.md#m03), [M04](SCREENS.md#m04), [M05](SCREENS.md#m05), [M06](SCREENS.md#m06), [M07](SCREENS.md#m07), [M08](SCREENS.md#m08), [M09](SCREENS.md#m09), [M10](SCREENS.md#m10), [M11](SCREENS.md#m11), [M12](SCREENS.md#m12), [M13](SCREENS.md#m13), [M14](SCREENS.md#m14), [M15](SCREENS.md#m15), [M16](SCREENS.md#m16)

수용 기준:

- 재연결 후 미확정 요청을 확인하고 중복 실행하지 않는다.
- PC가 꺼졌을 때 live 작업 가능으로 표시하지 않는다.
- 기존 PC 제어·Bluetooth·IME·파일 전송을 유지한다.

## F12 기존 운영 도구와 설정

전면 개선으로 현재 사용 가능한 기능이 사라지지 않는다.

- **시작:** 도구와 설정에서 모니터·OpenClaw·자동화를 연다.
- **동작:** 기존 상태와 수명 계약을 유지하면서 새 탐색에 배치한다. 모니터·패킷은 수집 범위를 드러내고 OpenClaw의 실행과 관리 연결을 구분한다.
- **화면:** [D12](SCREENS.md#d12), [D31](SCREENS.md#d31), [D34](SCREENS.md#d34), [D35](SCREENS.md#d35), [D38](SCREENS.md#d38), [D39](SCREENS.md#d39), [D40](SCREENS.md#d40), [D42](SCREENS.md#d42), [M12](SCREENS.md#m12), [M13](SCREENS.md#m13), [M15](SCREENS.md#m15)

수용 기준:

- 설치·연결·실행·사용 안 함 상태를 구분한다.
- 기존 사용자 테마·설정·기록을 보존한다.

## F13 내보내기와 외부 도구

기획을 보관·공유하고 이미 쓰는 협업 도구에 연결한다.

- **시작:** 내보내기 또는 외부 이슈·PR 연결을 선택한다.
- **동작:** 전체 프로젝트 백업은 원본·대화·로그·캡처를 기본 포함하며 인증은 제외한다. 외부 공유용 문서 내보내기는 목적과 포함 항목을 별도로 확인한다.
- **화면:** [D25](SCREENS.md#d25), [D26](SCREENS.md#d26), [D41](SCREENS.md#d41)

수용 기준:

- 내보낸 패키지에 기준 버전과 연결 관계가 포함된다.
- 연동이 없어도 로컬 기획과 실행을 사용할 수 있다.
- 다른 PC의 임시 프로젝트에 복원해 항목·참조·기록·캡처 해시를 대조한다. 인증·프로세스·실행 권한을 복원해 자동 실행하지 않는다.
- 기간 경과·용량 부족만으로 기록을 지우지 않는다. 삭제 전 대상·참조 영향을 보이고 활성 실행·확정본 필수 자료는 보호한다.

## F14 AI·Skills·MCP

사용자의 AI 도구를 통일된 맥락에서 사용한다.

- **시작:** 제공자 또는 도구를 설정하고 세션에 적용한다.
- **동작:** 기획·흐름·화면·조정·구현·검토·통합·일반 대화 프로필에 프롬프트·참조·제공자·모델·추론 수준·도구·권한·제한을 연결한다. Codex·Claude 구조화 대화를 유지하고 ACP 등 추가 adapter는 capability로 검증한다. 일반 CLI 사용과 구조화 대화를 구분하며 지원하지 않는 기능을 가장하지 않는다.
- **화면:** [D36](SCREENS.md#d36), [D37](SCREENS.md#d37), [M15](SCREENS.md#m15)

수용 기준:

- 활성화 전 실행 identity와 지원 기능을 확인한다.
- 다른 제공자에서도 지원되는 동일 동작은 같은 의미를 갖는다.
- 사용량을 제공하지 않는 경우 추정 수치를 표시하지 않는다.
- 실행 PC가 지원하는 모델·옵션만 선택하며 미지원 설정을 자동 대체하지 않는다.
- 화면 이동·프로필 미리보기는 AI 실행을 시작하지 않는다.
