# 확정한 제품 방향과 검토 근거

기존 제품 방향 C01–C12와 2026-10-13 최종 확인한 운영 정책 I01–I11을 기록한다. r6 전체 승인과 제품 구현 진행 지시는 [승인 기록](APPROVAL.md)에 별도 보존한다.

| ID | 결정 | 내용 |
| --- | --- | --- |
| C01 | 대상 | AI와 제품을 만드는 개인 사용자. 기획부터 검토까지 한 작업 맥락을 유지한다. |
| C02 | 작업 시작 | 제품 기획, 빠른 작업, 일반 대화, 터미널을 직접 선택한다. 일반 대화와 터미널에 PRD 작성을 강제하지 않는다. |
| C03 | 대화 | 말풍선과 터미널형은 같은 의미 기반 대화의 보기다. 실제 셸은 별도 세션이며 입력 대상이 항상 드러난다. |
| C04 | 플랫폼 | Windows와 Android를 각 구현 단계에서 함께 완성한다. 실행과 데이터의 권위는 PC에 있다. |
| C05 | 저장 | 기획 원본은 프로젝트 파일과 함께, 실행과 대화는 기존 런타임 저장소에 둔다. 서비스용 클라우드는 추가하지 않는다. |
| C06 | 편집 | AI의 초안 수정은 즉시 반영하며 변경 이력과 되돌리기를 제공한다. 확정본은 변경하지 않고 새 초안을 만든다. |
| C07 | 실행 | 단계별 검토가 기본이며 자율 실행도 선택할 수 있다. 자율 실행의 기본 종점은 로컬 통합과 검증이다. |
| C08 | 기존 기능 | 터미널, 원격, PC 제어, 모니터, OpenClaw, 자동화와 기존 설정을 유지하고 진입 위치를 재구성한다. |
| C09 | 시각 방향 | 차분한 현대적 작업 공간. 신규 기본값은 Dark와 말풍선이며 기존 설정은 보존한다. Matrix/CRT는 선택 테마다. |
| C10 | 협업 | 내보내기와 외부 이슈·PR 연결을 지원한다. 자체 다중 사용자 실시간 공동 편집은 범위에 넣지 않는다. |
| C11 | 로드맵 | 이번 제작의 단계·의존성·담당·완료 조건을 문서화한다. 제품의 작업 화면에 선행 작업과 검토 지점을 통합한다. |
| C12 | 구현 게이트 | 전체 상세 시안과 프로토타입 검토가 완료되고 사용자가 설계를 확정하기 전 제품 구현을 시작하지 않는다. |
| I01 | 요구사항 변경 | 영향 작업과 후속 의존 작업만 멈추고 변경 계획·재작업 범위를 확인받아 재개한다. 무관한 작업과 이전 기준·결과는 유지한다. |
| I02 | 빠른 작업 시작 | 목표·대상·범위·완료 조건을 담은 요약 카드에서 사용자가 실행한다. 전체 PRD는 요구하지 않는다. |
| I03 | 검증 실패 재시도 | 최초 검증 실패 후 기본 최대 2회 추가 수정·재검증한다. 횟수는 설정 가능하며 소진 시 시도와 남은 문제를 보존하고 사용자 판단을 기다린다. |
| I04 | 프로필 편집 | 모델·추론·지시문·참조 문맥·허용 도구를 직접 편집하고 저장·버전·되돌리기를 제공한다. AI도 수정안을 만들 수 있다. 상위 권한은 유지한다. |
| I05 | AI 프로필 수정 적용 | AI는 변경 전후와 이유를 제시한다. 사용자 적용 후 새 버전으로 저장하며 진행 중 시도는 고정된 설정을 유지한다. |
| I06 | 전체 기록 백업 | 기획·화면·확정본·역할 프로필·검토 기록과 대화 원문·실행 로그·캡처까지 기본 포함한다. 인증 정보는 제외하고 다른 PC에서 연결을 다시 확인한다. |
| I07 | Android 오프라인 | 최근 동기화 내용 열람과 메시지 초안 작성을 허용한다. 마지막 동기화 시점을 표시하며 재연결 후 사용자가 확인해 전송한다. |
| I08 | 기록 보관 | 전체 기록을 자동 삭제하지 않는다. 저장 용량을 보여 주고 사용자가 프로젝트별로 직접 정리한다. |
| I09 | 전체 실행 시간 | 전체 실행 시간 제한 없이 다음 검토·승인 지점까지 진행한다. 수동 중단과 검증 실패 재시도 제한은 유지한다. |
| I10 | 공통 UI 요소 | 반복 요소를 공통 원본에 연결하고 화면별 예외를 허용한다. 공통 변경은 연결된 초안에 반영하며 승인된 확정본은 유지한다. |
| I11 | AI 연결·사용량 장애 | 해당 작업을 대기시키고 중단 이유와 대체 AI 선택지를 보여 준다. 임의로 전환하지 않으며 독립 작업은 계속한다. |
