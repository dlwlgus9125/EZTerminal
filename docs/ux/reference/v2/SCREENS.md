## D01 프로젝트 홈

작업 목적에 맞는 시작점을 고른다.

- 진입: 앱 시작 또는 프로젝트 레일
- 구성: 시작 입력 → 작업 유형 3가지 → 최근 프로젝트 → 받은 요청 → 빠른 터미널
- 레이아웃: home
- 연결 기능: F01, F02, F10
- 리뷰: r6 전체 승인에 포함; 개별 화면 기록은 review-log.json과 브라우저 기록 참조

| 행동 | 결과·목적지 |
| --- | --- |
| 제품 기획 시작 | D02 새 프로젝트 · 가져오기 |
| 일반 대화 | D18 대화 · 세션 |
| 터미널 열기 | D28 터미널 |

| 상태 | 표시·복구 |
| --- | --- |
| ready | 검토용 예시 데이터가 표시된 정상 화면 |
| empty | 프로젝트가 아직 없습니다. 아이디어 입력 또는 폴더 열기로 시작합니다. |
| error | 최근 프로젝트를 읽지 못했습니다. 새 대화와 터미널은 계속 사용할 수 있습니다. |

수용 기준:

- 기획 절차 없이 대화와 터미널을 시작할 수 있다.

## D02 새 프로젝트 · 가져오기

기획 원본을 보관할 위치와 시작 자료를 정한다.

- 진입: 프로젝트에서 선택하거나 전체 검색으로 이동
- 구성: 프로젝트 이름 → 저장 폴더 → 새 기획/기존 폴더/패키지 → 가져올 자료
- 레이아웃: create
- 연결 기능: F01, F03
- 리뷰: r6 전체 승인에 포함; 개별 화면 기록은 review-log.json과 브라우저 기록 참조

| 행동 | 결과·목적지 |
| --- | --- |
| 프로젝트 만들기 | D05 PRD |
| 취소 | D01 프로젝트 홈 |

| 상태 | 표시·복구 |
| --- | --- |
| ready | 검토용 예시 데이터가 표시된 정상 화면 |
| error | 선택한 폴더에 저장할 수 없습니다. 다른 위치를 선택하세요. |
| conflict | 같은 위치의 기획 패키지를 발견했습니다. 기존 프로젝트 열기를 선택하세요. |

수용 기준:

- 취소는 폴더·프로젝트·세션을 생성하지 않는다.
- 없는 경로와 접근 불가 경로를 구분한다.

## D05 PRD

제품의 목적과 성공 기준을 합의한다. CLI 스킨은 메시지 기반 채팅의 표시 방식이며 셸이나 실행 모드가 아니다.

- 진입: 기획에서 선택하거나 전체 검색으로 이동
- 구성: 문서 목차 → 제품 목표 → 사용자와 문제 → 핵심 경험 → 범위·성공 기준 → AI 대화
- 레이아웃: document
- 연결 기능: F03, F04, F07
- 리뷰: r6 전체 승인에 포함; 개별 화면 기록은 review-log.json과 브라우저 기록 참조

| 행동 | 결과·목적지 |
| --- | --- |
| 직접 편집 | 검토용 동작 시뮬레이션 (edit) |
| 기능명세 열기 | D06 기능명세 |
| 변경 보기 | D13 버전 · 설계 확정 |

| 상태 | 표시·복구 |
| --- | --- |
| ready | 검토용 예시 데이터가 표시된 정상 화면 |
| empty | 아직 PRD가 없습니다. 아이디어를 설명하거나 직접 작성하세요. |
| working | AI가 제품 목표와 성공 기준을 정리하고 있습니다. |
| conflict | 이 문서에 외부 변경이 있습니다. 내 수정과 최신 문서를 비교하세요. |

수용 기준:

- AI 변경이 연결 기능의 검토 상태에 반영된다.
- 역할 지시·모델 또는 단계별 근거를 현재 맥락에서 확인하고 실제 실행과 검토 예시를 구분한다.
