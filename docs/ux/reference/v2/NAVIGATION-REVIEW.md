# 탐색 깊이 개선 · r2

사용자 피드백: 대화·세션 등의 화면에서 탐색이 두 겹으로 느껴진다. 이번 수정은 검토용 시안이며 활성 제품 계약과 제품 코드는 변경하지 않는다.

## 변경한 구조

기존 D18은 전역 레일 다음에 프로젝트 메뉴, 세션 목록, 대화, 산출물 목록이 연속해 배치됐다. 프로젝트 메뉴의 최근 대화와 별도 세션 목록도 중복됐다. 대화 제목·설명과 AI 헤더가 여러 줄을 차지해 실제 대화가 화면 안쪽에 들어간 느낌을 만들었다.

개선안은 상단의 영역 전환과 왼쪽의 항목 선택을 분리한다. 프로젝트의 개요·기획·디자인·대화·작업·검토·파일은 상단에서 바로 전환하고, 왼쪽에는 현재 영역의 목록 하나만 둔다.

```text
┌──────────────── 앱 헤더 ─────────────────────────┐
│레일│ 프로젝트 선택 │ 개요 기획 디자인 대화 작업 검토 파일 │
│    ├────────────┼───────────────────────────────┤
│    │ 대화 목록   │ 대화 제목 · 스킨 · 산출물 · 터미널    │
│    │ 검색        ├───────────────────────────────┤
│    │ 현재 대화   │ 대화                │ 산출물       │
│    │ 다른 대화   │                     │ 필요 시 펼침  │
│    │ 작업자 대화 │ 입력                │             │
└────┴────────────┴─────────────────────┴─────────────┘
```

프로젝트 → 작업 위치 → 세션이라는 실제 데이터 관계는 유지한다. 그 관계를 사용자가 항상 세 번 탐색해야 하는 UI 단계로 만들지 않는다. 현재 프로젝트는 선택기, 작업 위치는 세션의 보조 정보와 하단 위치 표시, 선택한 세션은 제목과 선택 상태로 드러낸다.

## 검토한 방향

| 방향 | 사용 경험 | 판단 |
| --- | --- | --- |
| 두 탐색 칸을 유지하고 접기만 제공 | 위치가 익숙하지만 기본 상태의 중복과 화면 깊이가 남음 | 보류 |
| 상단 영역 전환 + 단일 맥락 목록 | 영역과 항목을 한 번씩 직접 선택. 대화·파일·검토에 같은 구조 적용 | 이번 시안에 적용 |
| 대화만 표시하고 모든 탐색을 메뉴로 이동 | 본문은 넓어지지만 여러 세션과 기획을 오갈 때 매번 메뉴를 열어야 함 | 좁은 화면의 보조 방식으로만 사용 |

## 화면별 적용

| 화면 | 왼쪽 한 칸 | 중앙 작업 | 보조 영역 |
| --- | --- | --- | --- |
| D18 대화 | 현재 프로젝트의 세션·검색·기록 | 실제 대화 제목, 메시지, 입력 | 문서 또는 화면을 필요할 때 옆에 펼침 |
| D05 기획 | 기획 문서 목록 | 대화와 현재 문서를 나란히 편집 | 문서 도구 |
| D06 기능명세 | 기능 목록 | 선택한 기능·수용 기준 | 연결된 화면 |
| D10 화면 편집 | 화면과 해당 요소의 목록 | 편집 캔버스 | 선택 요소의 속성 |
| D20 검토 | 검토 요청 목록 | 선택한 결과·의견 | 변경·검증 렌즈 |
| D21 파일 편집 | 파일 트리 | 문서·편집기 | 저장 상태 |
| D22 변경 검토 | 변경 파일 목록 | 선택한 파일의 변경 | 라인 메모·검증 |
| 설정·도구 | 해당 범주의 메뉴 | 현재 설정 또는 도구 | 필요한 상태·제어 |

문서·캔버스·속성·대화처럼 실제 작업을 위한 병렬 영역은 유지한다. 같은 항목을 고르는 탐색 칸을 두 개 중첩하지 않는 것이 이번 변경의 기준이다.

## 동작·좁은 화면

- 세션을 선택하면 제목·담당·대화 내용이 같은 작업 영역에서 바뀐다. 이전 세션의 작성 중 입력과 스크롤은 해당 세션에 보존한다.
- `산출물 2` 또는 대화의 산출물 카드를 누르면 문서가 옆에 열린다. 같은 패널에서 요구사항·화면을 전환하며 대화를 다시 만들지 않는다.
- 넓은 화면에서 목록은 고정하고, 좁은 창에서는 `대화 목록 열기` 등의 버튼으로 서랍을 연다. Esc·닫기 후 원래 버튼에 focus를 돌려준다. 항목 선택 시 서랍을 닫는다.
- 산출물과 대화를 동시에 놓기 어려운 폭에서는 현재 본문 영역에서 전환한다. `대화로`는 입력과 읽던 위치를 복원한다.
- 목록을 숨겨도 프로젝트 영역 전환은 상단에 남는다. 대화 스킨 변경은 탐색 구조나 세션 정체성을 바꾸지 않는다.
- Android의 기존 한 화면·시트 중심 구조는 유지한다. Desktop에 상단 영역 전환을 추가했다고 모바일에 같은 탐색 줄을 중복하지 않는다.

정확한 제안 치수와 분기점은 [prototype.css](prototype.css)가 소유한다.
