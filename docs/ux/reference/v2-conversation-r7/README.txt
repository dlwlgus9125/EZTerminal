EZTerminal 2.0 · R7 확정 검토용 시안

미리보기: https://ezterminal-conversation-r6.brawnycake257.chatgpt.site
기존 R6 주소의 내용을 R7로 갱신했습니다. 화면 위의 R7 표시로 확인하세요.

검토 순서
1. '좌우', '상하', '1+2'로 배치를 바꾸고 영역 경계를 드래그합니다.
2. 각 영역에 초안을 작성하고 대화 탭을 다른 영역의 가운데/가장자리로 이동합니다.
3. '별도 창'을 눌러 실제 보조 창을 엽니다. 그 창에서도 분할할 수 있습니다.
4. 보조 창의 복귀 버튼 또는 창 닫기로 대화를 메인 창에 돌려놓습니다.
5. 휴대폰에서는 영역 전환 버튼으로 대화를 선택합니다. PC 폭으로 돌아가면 배치를 복원합니다.
6. 활성 대화 상태를 바꿔 승인, 대기열, 오류와 오프라인 화면을 확인합니다.

ZIP을 로컬에서 실행
압축을 풀고 dist 폴더에서 터미널을 연 뒤 실행:
  python -m http.server 4317 --bind 127.0.0.1
브라우저에서 http://127.0.0.1:4317 로 접속합니다.
창 사이 상태 전달을 위해 HTTP 서버가 필요합니다. index.html을 파일로 직접 열지 마세요.

검증
  pnpm e2e --config docs/ux/reference/v2-conversation-r7/playwright.config.cjs
8개 테스트 / 5개 화면 크기 × 3개 배치 × 10개 상태 = 150개 조합.
키보드, 드래그, 실제 팝업, 창 복귀, 상태 유지, 접근성을 검증했습니다.
evidence 폴더에 캡처와 자동 검사 결과가 있습니다.

범위
이 시안은 확정을 위한 인터랙티브 제안입니다. 아직 제품에 반영된 최종 승인안이 아닙니다.
대화, 실행 결과와 diff는 예시 데이터입니다. AI 실행이나 실제 파일 변경은 없습니다.
첨부는 파일 이름/크기 참조만 보관하며 파일 내용은 업로드하거나 저장하지 않습니다.
같은 창 안에서는 대화 프레임을 유지하며, 창 간 이동은 예시 상태를 직렬화해 전달합니다.
실제 Electron 제품의 동일 Dockview panel instance / provider / PTY 수명 보존은 별도 구현 검증이 필요합니다.
브라우저 팝업 차단 시 현재 대화가 유지됩니다. 창 밖 드래그는 팝업 정책상 확인 버튼을 거칩니다.
Android 실기기 키보드 및 실제 제공자 연결 검증, 성능 벤치마크는 수행하지 않았습니다.
