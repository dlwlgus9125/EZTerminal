# r3 기획 시작·전환 보완 계약

상태: 사용자 검토 후보. 활성 UX 계약을 대체하지 않습니다.

시각 기준은 [DESIGN.md](../../../../DESIGN.md), 활성 흐름·접근성 기준은
[frontend-design.md](../../frontend-design.md), 후보 전체 계획은
[agent-workflow-plan.md](../../agent-workflow-plan.md)입니다. 기존 runtime token과 Lucide를 사용하며
새 DESIGN 프로필·색상표·브랜드를 도입하지 않습니다. 구현 대상은 기존 `src/renderer/`와 `mobile/src/`입니다.

## 이번 시안의 변경

- 프로젝트 개요에서 새 기획·일반 대화·빠른 작업을 시작합니다.
- 기존 프로젝트 탭 아래에 현재 기획 이름과 기획 목록/추가 동작을 표시합니다. 새 탭 계층을 만들지 않습니다.
- 기획 목록은 이름/목적 검색과 진행·보관 필터를 제공합니다. 빈 프로젝트와 검색 결과 없음을 구분합니다.
- 기획 생성은 이름·목적만으로 시작하고 직접 작성과 AI 대화로 이어집니다. 생성·연결·대화 열기는 모델 턴이 아닙니다.
- 각 기획의 문서/대화/작업 상태를 분리합니다. 전환 시 기존 session, 입력과 문서 편집을 보존합니다.
- 일반 대화에서 새/기존 기획에 연결할 수 있습니다. 기존 기획을 고르면 문서를 덮어쓰지 않습니다.
- 기획 없는 빠른 작업은 별도 시작 카드를 사용합니다. 기획 목록에 항목을 만들지 않습니다.
- 이름 변경·보관·복원과 검토 후 수정 문서로 돌아오기를 제공합니다. 준비/진행 중 작업의 보관은 막고 안내합니다.

## 공통 대화와 플랫폼

[r1 기능 탐색 계약](../v2-agent-chat-r1/UI-CONTRACT.md)과 [r2 단계 연결 계약](../v2-agent-chat-r2/UI-CONTRACT.md)의
권한·지원 차이·명시 적용·확정본·실제 실행 경계를 유지합니다. Android는 기획 목록→내용 순서로
열고 보조 입력은 기존 dialog/sheet를 사용합니다. Desktop은 기존 한 칸 sidebar와 작업 영역을 유지합니다.

기획 제목/목적은 사용자 텍스트로 처리합니다. 버튼에 접근 가능한 이름을 제공하고 focus 표시와
dialog의 닫기/Tab 동작은 공통 시안에서 재사용합니다. 한영·테마·스킨은 동일한 동작을 유지합니다.
실제 모바일 Back, 네이티브 IME와 영구 저장은 이 HTML의 지원 범위가 아닙니다.

이 시안은 완료·보관 정책 전체나 다중 기획 데이터 이전을 구현한 제품이 아닙니다.
추가 구현 조건은 개선 계획을 따르고, 체험 가능한 범위는 README와 검토 기록을 따릅니다.
